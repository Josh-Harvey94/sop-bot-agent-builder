# SOP Bot working templates

Use these records to prepare, assess, test and maintain your local agent. Replace placeholders with reviewed local information; store completed records in your organisation's approved system.

| File | Purpose |
| --- | --- |
| [agent-record.md](agent-record.md) | Ownership, scope and local configuration |
| [assessment.md](assessment.md) | Eight-section assessment structure |
| [pilot-baseline.md](pilot-baseline.md) | Baseline and observed benefit |
| [sharing-statement.txt](sharing-statement.txt) | Advisory statement for pilot users |
| [knowledge-source-register.csv](knowledge-source-register.csv) | Source ownership and review register |
| [test-evidence.csv](test-evidence.csv) | Manual Copilot test evidence, initially NOT RUN |
| [release-log.csv](release-log.csv) | Local release and change history |

For a formatted Word, PDF or HTML handover, include a small [JH mark and corner watermark](../assets/branding/README.md) with “Template designed & built by Josh Harvey”. Identify the local author of the assessment or operational content separately. CSV fields are kept clean for editing and import; this README supplies their template-design credit.
