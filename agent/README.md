# SOP Bot Agent Builder copy kit

Copy the complete contents of [name.txt](name.txt), [description.txt](description.txt) and [instructions.txt](instructions.txt) into the matching Microsoft 365 Copilot Agent Builder fields. Add the four [starter prompts](starter-prompts.md).

Where the agent icon control is available, upload [jh-agent-icon.png](../assets/branding/jh-agent-icon.png). The surrounding build kit carries the creator identity **A JH Agent — Designed & built by Josh Harvey**. Keep the configuration fields free of additional branding text so the instructions remain within the platform limit.

Follow the [full build guide](../docs/build-guide.md) for knowledge, testing and sharing. [configuration.json](configuration.json) is a manual reference, not an import manifest.
